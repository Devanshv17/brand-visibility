## Overview

The dashboard displays AI shopping assistant (Rufus) visibility metrics for the Pedigree brand. All metrics are computed from **2,386 scraper results** across **34 JSON files**, covering **166 unique questions** and **3 persona-based topics**.

Each scraper result has this structure:
```json
{
  "input_question": "Can you recommend a dog food for picky eaters?",
  "answer_text": "Here are some options for picky dogs...",
  "products": ["PEDIGREE Chopped Ground Dinner (B00ABC123)", "Purina ONE (B00XYZ789)"],
  "questions": ["What about grain-free options?", "..."],
  "topic": "Picky_Eater",
  "run_id": 1,
  "latency": 15.5
}
```

## Dashboard Tab

### 1. Overall Visibility Score

**What it shows:** A single number (0–100) representing how often Pedigree products appear in Rufus AI recommendations.

**Calculation:**
```
For each unique question:
    prompt_visibility = (runs_where_pedigree_in_products / total_runs) × 100

Overall Score = average(all prompt_visibility scores)
```

**Example:** If a question was asked across 6 scraper runs and Pedigree appeared in the product list 3 times → that prompt's visibility = **50**.

**Current value:** 25/100

---

### 2. Visibility Trend Chart

**What it shows:** A 6-month line chart of visibility scores.

**Calculation:** Currently uses **placeholder trend data** — not computed from historical runs. The final data point matches the current overall score.

```
Sep: 28, Oct: 25, Nov: 23, Dec: 22, Jan: 23, Feb: 25 (current)
```

> **Limitation:** Real trend computation requires scraper runs tagged with dates. The current archive data doesn't have reliable timestamps per run.

---

### 3. Trend Delta

**What it shows:** The change vs. last month (e.g., `+3` or `-2`).

**Calculation:** Hardcoded to `-2` as a placeholder since historical data isn't available to compute a real delta.

### 4. Top Mentioned Competitors

**What it shows:** Brands that appear most frequently in Rufus recommendations alongside (or instead of) Pedigree.

**Calculation:**
```
For each scraper result:
    Extract brand names from the products[] array using keyword matching
    (e.g., "Purina ONE SmartBlend (B00XYZ)" → brand = "Purina")

Count how many results mention each brand (deduplicated per result).
Remove the target brand (Pedigree) from the list.
Sort by mention count descending.
Percentage = brand_mentions / total_non_target_mentions × 100
```

**Brand keyword list:** PEDIGREE, GREENIES, Blue Buffalo, Purina, Hill's, Royal Canin, Milk-Bone, Whimzees, DentaLife, Merrick, Wellness, CESAR, IAMS, NUTRO, and others.

### 5. Top Citation Sources

**What it shows:** Where the AI answer's information comes from.

**Calculation:** Counts how many scraper results contain each type of response component:

| Source | How Counted |
|--------|------------|
| **Product Listings (PDP)** | Number of results that have a non-empty `products[]` array |
| **AI Answer Content** | Number of results that have a non-empty `answer_text` field |
| **Follow-up Questions** | Number of results that have a non-empty `questions[]` array |

```
Percentage = source_count / (pdp_count + answer_count + followup_count) × 100
```

> **Limitation:** These are not true citation sources. A real implementation would parse the AI answer to identify whether it's citing product detail pages, customer reviews, Q&A sections, or external websites.

### 7. Topic-Level Visibility

**What it shows:** Average visibility score for all prompts within a topic.

**Calculation:**
```
topic_visibility = average(visibility_score for each prompt in topic)
```

---

### 8. Monthly Volume (per prompt)

**What it shows:** Estimated search volume displayed as `5K+`, `2K+`, `1.2K+`, or `<1K`.

**Calculation:** A **heuristic** based on how many scraper runs included this question:

```python
if len(runs) >= 8:  volume = "5K+"
elif len(runs) >= 5: volume = "2K+"
elif len(runs) >= 3: volume = "1.2K+"
else:                volume = "<1K"
```

> **Limitation:** This does not reflect actual Amazon search volume. Real monthly volume would require integration with Amazon's search analytics or third-party keyword tools.

## Prompts Tab (Prompt Library)

### 9. Per-Prompt Visibility Score

**What it shows:** How consistently Pedigree appears in AI answers for this specific question.

**Calculation:** Same as described in §1, but at the individual prompt level:
```
visibility = (runs_with_pedigree_product / total_runs_for_this_question) × 100
```

---

### 10. Visibility Outcome (Brand Wins / Competitor Wins / No Clear Winner)

**What it shows:** Whether the brand or a competitor dominates the AI response for this prompt.

**Calculation:**
```python
if visibility_score >= 50:
    outcome = "brand_wins"
elif top_competitor_mention_count > brand_mention_count:
    outcome = "competitor_wins"
else:
    outcome = "no_clear_winner"
```

---

### 11. Top Competitor (per prompt)

**What it shows:** The most frequently mentioned non-Pedigree brand for this question.

**Calculation:**
```
For all runs of this question:
    Extract brands from products[] array
    Remove Pedigree
    Count occurrences of each brand
    Return the brand with the highest count
```

---

### 12. Coverage Status

**What it shows:** Whether the brand is adequately represented in AI responses.

**Calculation:**
```python
if visibility_score >= 50:  status = "Covered"
elif visibility_score > 0:  status = "Partially Covered"
else:                        status = "Not Covered"
```

**Current breakdown:**

| Status | Count |
|--------|-------|
| Covered | 43 |
| Partially Covered | 33 |
| Not Covered | 90 |

---

### 13. Journey Stage

**What it shows:** Where in the purchase funnel the question falls (Discovery, Evaluation, Conversion).

**Calculation:** Keyword-based heuristic on the question text:

```python
if any(w in question for w in ["compare", "vs", "difference", "choose", "better"]):
    stage = "Evaluation"
elif any(w in question for w in ["buy", "purchase", "order", "stock up", "switching"]):
    stage = "Conversion"
else:
    stage = "Discovery"
```

> **Limitation:** Most questions fall into "Discovery" because of the broad default. A more accurate classification would use NLP or manual tagging.

---

### 14. Priority

**What it shows:** Importance level of the prompt (High, Medium, Low).

**Calculation:** Based on the number of scraper runs:
```python
if len(runs) >= 5:  priority = "High"
elif len(runs) >= 3: priority = "Medium"
else:                priority = "Low"
```

---

### 15. Stability (Stable / Volatile)

**What it shows:** Whether the AI's response is consistent across runs.

**Calculation:**
```python
# For each run, check: does Pedigree appear? (True/False)
per_run_outcomes = [has_pedigree_in_products for each run]

if all outcomes are the same:  stability = "Stable"
else:                           stability = "Volatile"
```

A prompt that always includes Pedigree (100%) or never includes it (0%) is **Stable**. A prompt that sometimes includes it and sometimes doesn't is **Volatile**.

---

### 16. Coverage Evidence (Snippets)

**What it shows:** A text snippet from the AI answer where the brand was mentioned.

**Derivation:** Finds the first answer text that mentions "PEDIGREE" and extracts ~110 characters around the mention.

```python
position = answer_text.lower().find("pedigree")
snippet = answer_text[position-30 : position+80]
```

## Known Limitations

| Metric | Limitation | Ideal Solution |
|--------|-----------|----------------|
| Monthly Volume | Heuristic from run count, not real search data | Amazon search analytics API |
| Citation Sources | Counts response components, not actual citation types | Parse AI answers for source attribution |
| Journey Stage | Keyword matching, most default to "Discovery" | NLP classification or manual tagging |
| Visibility Trend | Placeholder data, not historical | Tag runs with dates, compute per-period scores |
| Trend Delta | Hardcoded `-2` | Difference between latest and previous period |
| Surface Detection | Only PDP reliably detected | Parse answer structure for review/Q&A citations |
| Priority | Based on run count, not business importance | Manual assignment or search volume weighting |
